# Design

<!-- impeccable:design-schema 1 -->

## Direction

An operating instrument for a private telemetry stream. The first viewport is a live signal field: sessions are measured traces, not dashboard cards. The interface is calm charcoal with mineral-blue structure and amber reserved for attention states.

## Mode

Operate. The user scans recent activity, spots a change in model/cache/context, and drills into one session without opening raw logs.

## System

- Dark graphite ground, cool blue rules, warm amber for warnings, pale data ink.
- Humanist sans for reading; tabular numerals for token and cost measurements.
- Dense horizontal event rows, thin dividers, square-ish instrument controls, restrained 10px corners.
- One motion: a live status pulse that stops under reduced-motion.

## Boundaries

No message text, command text, tool output, credentials, or raw JSON is rendered. Values are local estimates and their labels say so.
